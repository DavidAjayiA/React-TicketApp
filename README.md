# Ticketly — React Full Implementation (Local Mock)
## What you get
- Vite + React app with routing, simulated auth (localStorage), Dashboard, Ticket CRUD (localStorage), validation and toast notifications.
- Session token stored in localStorage under the key `ticketapp_session`.
- Mocked ticket store under localStorage key `ticketapp_tickets_v1`.

## Quick start
1. Ensure Node 18+ and npm installed.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the URL Vite reports (usually http://localhost:5173).

## Test user credentials
- Any non-empty email/password works for demo.

## Notes
- This is frontend-mock only (no real backend). For production you'd plug a backend API.
